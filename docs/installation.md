# Installation

## Requirements

- Python 3.12+
- VS Code or Cursor with a compatible CLI (`code`, `cursor`, or `code-insiders`)

## Install via uv (recommended)

```bash
uv tool install ext-tool
```

## Install via pipx

```bash
pipx install ext-tool
```

## Install from source

```bash
git clone https://github.com/joeblackwaslike/ext-tool.git
cd ext-tool
uv sync
uv run ext --help
```
