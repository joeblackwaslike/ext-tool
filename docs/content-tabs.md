# Content Tabs

## Installing on different editors

=== "Cursor"

    ```bash
    EXT_HELPER=cursor ext install
    ```

=== "VS Code"

    ```bash
    EXT_HELPER=code ext install
    ```

=== "VS Code Insiders"

    ```bash
    EXT_HELPER=code-insiders ext install
    ```

## Export formats

=== "TOML"

    ```bash
    ext export my-extensions.toml
    ```

=== "JSON"

    ```bash
    ext export my-extensions.json --format json
    ```

=== "CSV"

    ```bash
    ext export my-extensions.csv --format csv
    ```
